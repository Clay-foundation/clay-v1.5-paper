# E2c_posemb_ablation — does Clay's GSD position code limit spatial information in patch tokens? (3 training seeds; Amendment 1, 2026-11-06)

**Setup.** We trained the same small Clay MAE (`clay_mae_small`, 14.6 M parameters, pinned Clay `Encoder`/`Decoder`/`DynamicEmbedding`) from scratch with three position codes, in lock-step within each seed. **A** is Clay's implemented `posemb_sincos_2d_with_gsd`, with ViT-L's frequency spread (all within 1.8 % of g rad/token). **B** is the standard 2-D sin-cos code. **C** is the standard code with positions scaled by gsd/10 m (Scale-MAE style; equal to B at 10 m). Training was reconstruction only (no teacher), with metadata zeros, for 80,000 steps at batch 64 on E2's 10,219 non-test chips. Following Amendment 1 there are three training seeds (0, 1, 2), which differ in initial weights, batch/augmentation stream and masks. Evaluation used E2's held-out test chips, token positions, heads and labels (S2 535 chips / 328 blocks; NAIP 309 / 110). Pooled contrasts are means over seeds. Two 95 % intervals are given: **[h]** a hierarchical bootstrap (1,000 shared block resamples × seeds resampled) and **[t]** a seed-level t-interval (n = 3). A contrast is "robust" only if both exclude 0. The seed-0 report is kept as `RESULTS_seed0.md`, and its numbers are unchanged; re-embedding seed 0 from its checkpoints reproduced them exactly.

**Primary endpoint (S2 position R², B − A): −0.011, [h] −0.019 to −0.001, [t] −0.033 to +0.012. Not robust.** The per-seed contrasts are −0.019, −0.011 and −0.001. A decodes position at R² 0.995 in all three seeds. B reaches 0.976, 0.984 and 0.994, and C 0.961–0.970. No seed shows the standard code adding position, and the largest gain the data allow is about +0.01 R². That is far below the 0.6 R² gap between Clay v1.5 and DINOv2 that motivated the test. The other sensors agree. B − A is −0.003 on S1, −0.007 on Landsat and −0.011 on NAIP ([h] −0.019 to +0.001), with every arm and seed ≥ 0.96. This happens even though code A on its own is almost not linearly decodable (R² 0.09 at 10 m); the network turns it into readable position. **Answer:** in this controlled small-model setting the implemented code does not reduce the position information in patch tokens. E2's weak position in Clay v1.5 tokens (R² 0.24–0.48) is therefore not explained by the code. Depth and scale, DINOv2 distillation, metadata and training length remain untested.

**Land cover and reconstruction (secondary): the implemented code costs quality, robustly.** Per-token WorldCover macro-F1, B − A:
- S2 +0.071 ([h] 0.046–0.098; [t] 0.054–0.089), A 0.477–0.490 vs B 0.551–0.564
- S1 +0.065 (0.053–0.088; 0.057–0.074)
- Landsat +0.078 (0.052–0.108; 0.047–0.109)
- NAIP +0.034 (0.000–0.063; 0.003–0.065)

All four are robust, NAIP marginally. Held-out masked L1, B − A, is robust on every sensor (lower is better): S2 −0.028 (−0.031 to −0.024; −0.035 to −0.020), S1 −0.016, Landsat −0.021, NAIP −0.055 (−0.063 to −0.047; −0.069 to −0.040). B's training loss was the lowest in every seed (final 1k-step means A 0.185–0.191, B 0.157–0.165, C 0.174–0.182). The GSD-scaled code C also beats A on F1 (S2 +0.054, robust on S2, S1 and Landsat; NAIP +0.027, not robust). Its reconstruction is robustly worse than B's on every sensor (S2 +0.015 L1), and its F1 is below B's on S2 (−0.018; robust only on S1).

**What it means.** Clay's near-single-frequency code does not stop a small transformer from representing where a token is. It does make the MAE task harder, and the patch tokens 3–8 F1 points worse for dense land cover. A plain sin-cos code was better than both GSD-aware codes here. Whether this holds for the ViT-L with distillation is unknown.

**Caveats.** Small model (6 layers, 384-d), 80k steps on 10 k chips, so **results do not transfer automatically to Clay v1.5's ViT-L.** n = 3 seeds makes the t-intervals wide, and the seed resampling in [h] under-states seed variance. For position, seed-to-seed spread (B 0.976–0.994) is larger than the block-bootstrap width. In seed 0, the position contrasts changed sign between 40k and 80k steps on NAIP, so they depend on training length. Linear probes only. The arm-A code uses the ViT-L frequency spread, not the literal small-model call. No teacher loss, metadata zeros, no extra chips, no random crops. E2's sampling (57 % CONUS) and label caveats apply.
