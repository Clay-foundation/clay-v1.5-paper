This repository holds the technical report for Clay v1.5, the evaluation code behind it, and the result files every number in the report comes from.

- **Read the report:** [`Clay-v1.5-arxiv.pdf`](Clay-v1.5-arxiv.pdf), or [`DRAFT.md`](DRAFT.md) to read it on GitHub.
- **Check a number:** [`docs/FACT_SOURCES.md`](docs/FACT_SOURCES.md) maps each claim to a public source or to a file in [`experiments/results/`](experiments/results/).
- **Reproduce it:** [`REPRODUCING.md`](REPRODUCING.md), or run the CPU checks in Colab with [`notebooks/reproduce_checks.ipynb`](notebooks/reproduce_checks.ipynb).
- **Tell us what is wrong:** [open an issue](../../issues/new/choose). See [`CONTRIBUTING.md`](CONTRIBUTING.md).

The report is a preprint under open review.

## The model

Clay v1.5 is a ViT-L/8 masked autoencoder conditioned on band wavelengths and ground sample distance, so one frozen checkpoint embeds imagery from different sensors and resolutions.

| | |
|---|---|
| Code | https://github.com/Clay-foundation/model (Apache-2.0) |
| Chipping pipeline | https://github.com/Clay-foundation/stacchip (Apache-2.0) |
| Weights | https://huggingface.co/made-with-clay/Clay, file `v1.5/clay-v1.5.ckpt` (Apache-2.0) |
| Weights SHA-256 | `21432069250b9b3f9a65ffd0071c5ad56b793247285ab0604edf7f531d4798d0` |
| Embedding catalogs | https://source.coop/clay (CC BY 4.0) |

Three model generations have released checkpoints. Earlier ones and the compiled encoders now live in `made-with-clay/Clay-legacy`.

| Release | Date | Backbone | Encoder parameters | Embedding | Checkpoint |
|---|---|---|---:|---:|---|
| Clay v0 | Jan 2024 | Fixed-band ViT-B/32, 512 px chips | 95.3M | 768-D | `Clay-legacy`: `v0/Clay_v0.1_epoch-24_val-loss-0.46.ckpt` |
| Clay v1.0 | May 2024 | Dynamic ViT-B/8 | 92.1M | 768-D | `Clay-legacy`: `v1/clay-v1-base.ckpt` |
| Clay v1.5 | Nov 2024 | Dynamic ViT-L/8 | 311.4M (327.3M with the MAE decoder) | 1024-D | `Clay`: `v1.5/clay-v1.5.ckpt` |

Parameter counts and file digests are regenerated by [`experiments/inspect_remote_checkpoint.py`](experiments/inspect_remote_checkpoint.py) and [`experiments/table1/`](experiments/table1/). Guidance on how to use the model (which token to read, what to pass when time or location is missing, which probe to fit) is in Section 2.3 and Section 4 of the report.

## Reproducing

```bash
curl -LsSf https://astral.sh/uv/install.sh | sh   # uv
make env      # pinned environment from uv.lock
make smoke    # CPU: downloads the checkpoint, verifies its digest, reproduces one published number
make tables   # regenerates the Table 1 and Table 2 summary numbers from the result files
make paper    # builds the PDF and the arXiv source archive (not committed), and runs the consistency gates
```

Each experiment family has its own `make` target with its runtime, GPU need and input data. [`REPRODUCING.md`](REPRODUCING.md) lists them and says which steps have been re-run from a clean checkout and which have not.

## Layout

| Path | What it is |
|---|---|
| `DRAFT.md` | The manuscript in Markdown |
| `latex/` | The same manuscript in LaTeX, with `references.bib` |
| `Clay-v1.5-arxiv.pdf` | Compiled PDF. `make paper` also writes the arXiv source archive, which is not committed |
| `build.py` | Builds the figure, PDF and archive, and checks that `DRAFT.md` and `latex/` agree |
| `generate_figures.py`, `figures/` | Figure 1 and its generator |
| `docs/FACT_SOURCES.md` | Claim-by-claim source ledger |
| `docs/DATA_LICENSES.md` | Licence and attribution for each dataset and external artifact |
| `experiments/results/` | Result files behind the tables and the text |
| `experiments/table1/`, `experiments/table2/` | Scripts and cell lists that regenerate Tables 1 and 2 and their summary statistics |
| `experiments/run_*.py` | Benchmark runners for Table 2 and the Section 4 experiments |
| `experiments/suite/` | Experiments E1–E8: protocol, code and results for each, plus the shared runtime in `common/` |
| `pyproject.toml`, `uv.lock`, `Makefile` | Pinned environment and entry points |
| `notebooks/reproduce_checks.ipynb` | Colab notebook that runs `make env`, `make tables` and `make smoke` from a clean clone |

`DRAFT.md` and `latex/` are kept in step by hand; `python3 build.py` fails if sections, tables, figures or citations differ between them.
